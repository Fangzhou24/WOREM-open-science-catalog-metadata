# WOREM Open Science Catalog Metadata

This repository contains metadata for the **GLOBAL INVERSION DATASET** (**NOx, NH3, SO2**) developed within the **ESA WORLD EMISSION (WOREM)** project, for ingestion into the **Open Science Catalog (OSC)** platform.

## About the Open Science Catalog (OSC)

The **Open Science Data Catalog** is an ESA Open Science activity that aims to improve the discoverability and reuse of scientific and value-added results (e.g., **data, code, documentation**) produced by ESA Earth Observation–funded Earth System Science research.

The catalog provides open access to geoscience products based on EO data (ESA and non-ESA missions) as well as other geospatial information and models. It follows the **FAIR principles** and promotes **reproducibility**. The platform uses open-source geospatial technologies including **pycsw**, **PySTAC**, and **OpenLayers**, and aims to contribute back through software and standardisation.

- Website: https://opensciencedata.esa.int

## About the WORLD EMISSION (WOREM) project

The ESA-funded **WORLD EMISSION** project kicked off on **4 March 2022**. It aims to develop an enhanced global emission monitoring service by producing **top-down emission estimates** based on satellite observations. These estimates are compared with **bottom-up inventories**, in collaboration with end-user organisations, to define product requirements.

### Project ambitions

The WORLD EMISSION team aims to develop an emission inventory system that:

- Monitors multiple species, including: **CH4, CO2, H2O, NH3, SO2, NO2, PM, CO, CH3OH (methanol), CH2O (formaldehyde), CHOCHO (glyoxal), isoprene**.
- Increases the spatial and temporal resolution of existing inventories using high-resolution satellite data.
- Provides a global processing framework capable of handling regional heterogeneity.
- Covers emissions across scales, including:
  - point sources (large industrial sites),
  - hotspots (oil/gas/coal extraction basins),
  - forest fires and megacities,
  - regional and national totals.
- Attributes anthropogenic emissions to socioeconomic sectors.
- Integrates species-specific processing into a unified workflow.
